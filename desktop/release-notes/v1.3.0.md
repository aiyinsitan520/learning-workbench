### 日计划
- 时间块上下沿都能拖：拖上沿改开始时间，拖下沿改时长，手柄更好抓；键盘 ↑ / ↓ 也能调（Shift 为 15 分钟）。
- 时间轴可切换紧凑 / 舒适 / 宽松三档，也可以按住 Ctrl 滚动滚轮切换。
- 右栏长期项目可以按住拖进左栏日计划（项目卡不动），或直接点「排进今天」放进第一个空档。

### 右键菜单
- 时间块、时间轴空白处、左栏待办、长期项目卡、收获卡都有右键菜单：改时长、复制到明天、移到下一个空档、写今天进展、复制为 Markdown 等常用操作。
- 时间块可以 Ctrl+C 复制、Ctrl+V 粘贴；键盘上用 Shift+F10 打开菜单。

### 收获
- 卡片重新设计：结论突出、要点可展开、彩色标签、来源域名、星标。
- 可以关联到项目或任务；项目卡上显示「收获 N」，点开就是这个项目的收获。
- 新增复习：「今天待复习」翻卡复习、「随便看一张」；有该复习的卡片时顶栏「收获」亮小红点。
- 要点和待办点一下就能直接改，可排序；卡片上可以加图片。

### 任务正文
- 可以直接粘贴、拖入或选择图片，正文里显示缩略图，支持 Markdown 预览。

### 数据
- 齿轮里新增「数据与备份」：看清数据存在哪个文件夹、占多少空间，一键备份，更换数据文件夹（旧文件夹不会删除）。
- 网页版和桌面版可以共用同一个数据文件夹，一边改，另一边实时更新。
- 可以把任务正文和收获单向导出到 Obsidian 仓库，图片一起带过去。

### 新手引导
- 第一次打开有欢迎卡和 1 分钟引导；顶栏新增「?」帮助：功能速查、快捷键表，随时重看引导。

升级后第一次启动会自动升级数据库，升级前先在数据文件夹里自动备份一份。
