## 接口约定

### 1. `POST /api/attachments/fetch`（新）

- 请求：`Content-Type: application/json`，体 ≤ 4 KiB，`{ "url": string }`，url ≤ 2048 字符。受现有 Host/Origin 守卫保护（放在守卫之后）。
- 成功：与 `POST /api/attachments` 完全同形 `{ id, url, bytes, type }`，同一存储与去重（共用 `storeAttachment(bytes, type, dataDir)`；`uploadAttachment` 行为不变）。
- 错误码：400 `invalid-url`（非 http/https、含用户名密码、解析失败、体不是 JSON）；403 `blocked-address`；409 `no-data-folder`；413 `attachment-too-large`；415 `invalid-image`；502 `fetch-failed`（非 200、连接失败、重定向过多）；504 `fetch-timeout`。

### 2. `app/lib/remote-image.js`：`fetchRemoteImage(url, options?) → { bytes, type }`，失败抛带 `code`/`status` 的错误

安全要求（全部必须有单元测试）：
- 只允许 http/https；拒绝 URL 内用户名/密码。
- 先 `dns.lookup(host, { all: true })`；**任一**地址非公网即 403。非公网含：0/8、10/8、100.64/10、127/8、169.254/16、172.16/12、192.0.0/24、192.168/16、198.18/15、224/4、240/4、255.255.255.255；IPv6 的 ::、::1、fc00::/7、fe80::/10、ff00::/8，以及 ::ffff: 映射的上述 IPv4。主机名本身是 IP 字面量也同样判定。
- 连接时用自定义 `lookup` 固定到已校验的地址（防 DNS 重绑定），不再二次解析。
- 重定向手动跟随，最多 3 次，每跳重新做协议与地址校验。
- 总超时 10 秒；流式读取超过 10 MiB 立即中止 413；只认 200。
- 类型只看文件头魔数（复用 attachments.js 的 FORMATS），不信响应的 Content-Type；不支持 SVG。
- 不带 Cookie、不带 Referer；`Accept: image/*`；`Accept-Encoding: identity`；User-Agent 用通用字样，不含用户信息。
- `options` 只为单元测试：可注入 `lookup` 与 `isAllowedAddress`。**server.js 路由不得传 options**，`start()` 签名不变。

### 3. 前端 `task-notes.js` 粘贴规则

按顺序判断，先命中先处理：
1. 剪贴板有图片文件 / file 项 → 现有上传流程（不变）。
2. `text/html` 里至少有一张可取的 `<img>`（src 为 `data:image/(png|jpeg|webp|gif);base64`，或 `http(s):`）→ 拦截粘贴，**图文都保留**：
   - 在惰性 `<template>` 里解析（不加载外部资源），按文档顺序把 HTML 转成纯文字：文本节点合并空白；p/div/li/h1–h6/tr/blockquote/pre/section/article 前后换行；`<br>` 换行；li 前加 `- `；script/style 内容丢弃；连续空行最多保留一个。
   - 每张图在原位置占一行：`data:` 图走现有 `POST /api/attachments`，`http(s)` 图走 `POST /api/attachments/fetch`；成功变成 `![alt](/api/attachments/<id>)`，失败则该图不留痕迹，计入失败数。
   - 一次最多处理 20 张，超出的不取并提示。
   - 上传期间沿用 `![上传中…]()` 占位与 32000 字上限规则（超限截断并提示，同现状）。
   - 上一批还在上传时又粘贴含图 HTML：`preventDefault` 并提示「上一批图片还在上传，稍候再按一次 Ctrl+V」（剪贴板内容没丢）。
3. `<img>` 全是 `file:`、`blob:` 或其他读不到的地址 → 不拦截（原生粘贴文字），状态栏提示「有 N 张图片来自本机文件，网页读不到，请用「从文件插图」或拖入」。
4. 其他 → 原生粘贴，不变。

状态栏提示用人话：成功不提示；部分失败「有 N 张图片没取到（网址打不开或不是 PNG/JPEG/WebP/GIF）」。
