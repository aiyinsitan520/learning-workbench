# 学习工作台 · 可运行实现

根目录的 `index.html` 是交互对照样稿（数据在内存里）。这里是它的真实实现：
数据落在本机 SQLite，刷新和重启都不丢。

## 运行

日常使用：双击桌面「学习工作台」快捷方式（白猫图标，指向 `启动学习工作台.ps1`）。服务没在跑就在后台启动、不留黑窗口，然后用 Chrome 应用模式（`--app`）开一个独立窗口；窗口已开着就把它带到前面。改了 `app/public/` 下的页面文件，在窗口里按 Ctrl+R 即生效；改了 `server.js` 或 `lib/` 需先运行停止脚本再双击快捷方式。关掉浏览器不影响服务，要停止时运行 `停止学习工作台.ps1`（只停 `app\server.js`）。后台日志在 `app\data\server.log(.err)`。重启电脑后需要再双击一次快捷方式。


双击项目根目录的 `学习工作台.cmd`，或在命令行里：

```powershell
node app\seed.js      # 可选：灌一份示例数据
node app\server.js    # 启动，默认 http://127.0.0.1:7321/
```

环境变量：`PORT`（端口）、`WORKBENCH_DB`（数据库路径）、`WORKBENCH_TZ`（时区，默认取系统）。

要求 Node.js 22 或更新版本（用到内置的 `node:sqlite`）。**没有任何第三方依赖**，
不需要 `npm install`。启动脚本会检查版本，过低时直接给出提示而不是抛一堆栈。

## 备份与迁移

左栏底部「我的工作台」右边的下载图标，或直接访问 `http://127.0.0.1:7321/api/export`，
会把整库导出成一份 JSON（任务、排期、专注、手记、块）。

导入只接受空库，避免覆盖：

```powershell
curl -X POST http://127.0.0.1:7321/api/import `
  -H "content-type: application/json" `
  --data-binary "@workbench-2026-11-20T08-44-37.json"
```

非本工作台的文件返回 400，库里已有数据返回 409。

## 与架构文档的对应

- `architecture/workbench.d.ts` 的 `Command` 全部实现；`WorkbenchView` 由 `GET /api/view` 返回。
- `architecture/schema.sql` 是唯一的建表来源，代码不重复定义表结构。
- 专注：全库最多一条 `running`/`paused`，由唯一索引兜底，应用层先查后写给出可读错误。
- 任务正文：按任务 ID 存储，`expectedRevision` 不匹配返回 409，前端保留草稿。
- 每日手记（旧）：接口与表仍保留，整篇一次事务写入；前端已不再提供编辑入口。
- 统计：秒级累计，分钟只在展示层换算。

## 键盘快捷键

| 键 | 作用 |
| --- | --- |
| `1`–`5` | 切换页面（今日 / 日历 / 专注 / 统计 / 昨日） |
| `N` | 聚焦新建任务输入框 |
| `空格` | 在专注页开始 / 暂停 / 继续 |

## 已实现

- 五个页面：今日工作台、日历、专注、学习统计、每日维护。入口在顶栏分组工具条，选中底板随切换滑动；顶栏齿轮进入「模型接入」。
- 每日维护（快捷键 5）：默认看昨天，数字卡、AI 回顾（用「模型接入」里的当前模型，结果缓存在库里）、没做完的计划一键顺延到今天、长期项目进展、保存图片。
- 长期项目（右栏）：跨多天的目标，自带主任务（可拖进日计划、开始专注、写正文），显示第几天、剩几天、今日投入。
- 模型接入（齿轮）：CC Switch 式供应商管理，内置常见预设，可获取模型列表、测试连接、导入 CC Switch / Codex 配置；Key 只存 app/data/ai-providers.json，任何接口和导出都不含 Key。
- 任务：新建、改名、排期、改期、取消排期、完成、撤销完成。
- 任务正文：点击左侧待办或计划块，直接在今日工作台编辑，是唯一的书写入口。各任务按 ID 保存独立正文，短暂停键或切换任务时自动保存到 SQLite。保存失败保留草稿并可重试，正文随整库备份导出。
- 左栏计划覆盖当天 06:00–24:00。按住任务块主体上下拖动，以 5 分钟为步长改期，单击打开任务正文。只有底边可以调整时长（悬停显出把手），也支持底边聚焦后使用方向键。
- 「计划」视图新建任务时，默认接在当天最晚结束的时间块之后，空计划从 06:00 开始。默认 30 分钟，临近午夜时用剩余时间。时间轴的「＋」沿用这一开始时间，点空档可另选时间。
- 「待办」视图在时间轴上方显示清单。这里新建任务先进入待办，可拖动任务标题到时间轴排期，排过的任务仍保留在清单中。
- 只属于日计划的事项：在「计划」视图新建，或在「添加时间块」弹窗里写一个新名字，课程字段记为「日计划」，只出现在时间轴上，不进待办清单、不计入「未完成任务」。弹窗里以标签列出待办清单，点选即把那个待办排进去。无库表变更。
- 左栏可折叠成图标轨道（每个待办取标题首字），状态记在本机。顶栏「圆体」开关在圆体与系统字体之间切换。
- 六套皮肤：顶栏「皮肤」按钮打开选择器，奶糖 Mac（默认，可爱圆润）、薄荷、拿铁、摩卡夜（深色）、极光（系统字体、小圆角）、晨玫瑰（衬线标题）。选择记在本机，首屏前套用不闪烁；配色来自 Catppuccin、Nord、Rosé Pine（MIT）。
- 专注：开始、暂停、恢复、提前结束、到时自动结算；全库最多一轮开放专注；支持不绑定任务的自由专注；切页时计时不断。
- 切页保留各页滚动位置。
- 管家：贾维斯喵浮层，复用同一套命令，从猫入口和专注页入口得到同一条记录。
- 统计：按日汇总，秒级累计，分钟只在展示层换算。

## 已知边界

- 单机单用户，服务只绑定 `127.0.0.1`，没有账号与同步。
- 时间块按开始时刻归到某一天，跨天时间块不会拆分显示。
- 旧的「学习笔记 / 学习流程」页已于 2026-11-20 撤下。库里已有的每日手记保留，仍随整库导出，日历以「旧手记」显示标题，每日维护仍会统计。
- 导入只支持空库，不做合并或冲突解决。
- 没有桌面壳（Tauri），也没有 Mac 原生版本；当前是本机 HTTP 服务。
- 视觉方向：素材库 shell-001（Mac 分组工具条 + 内嵌侧栏）、navigation-002（可折叠侧栏），灵动岛参考 overlay-001。未做深色模式。


## 给 AI 读取数据

在项目根目录右键「导出给AI.ps1」，选择「使用 PowerShell 运行」，或执行 `node app/tools/export-ai.mjs --days 30`。导出目录为 `app/data/ai-export/`，包含 JSON、Markdown 和数据口径说明。任务正文默认省略，按需通过命令行加 `--notes`。

接口、SQLite 字段和分析提示词示例见 [给 AI 读取学习工作台数据](../docs/DATA_FOR_AI.md)。
