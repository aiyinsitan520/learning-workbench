# 收获速记

把与 AI 聊完后值得留下的结论、要点和待办存成小卡片。工作台只保存卡片，原文不保存。卡片会进入当天的 AI 回顾，也会随所选日期范围导出给 AI。

1. 在 ChatGPT 打开「设置 → 个性化 → 自定义指令」，粘贴下面的口令。菜单名称可能随版本变化，也可以把口令存成常用消息，需要时发到对话里。
2. 问完后单独发「收」，让 ChatGPT 把精华放进一个代码块。
3. 点代码块的复制按钮，回到工作台按 `Ctrl+Shift+V`（Mac 为 `⌘+Shift+V`），检查卡片并保存。

如果粘贴的是原文而不是固定格式，可以点「用 AI 提炼」，由「模型接入」里的当前模型提炼，费用按你自己的模型计费；没设模型时也可以手动填写。卡片里的待办可以「加入待办」或「排进今天」。按 `6` 打开收获页。

## ChatGPT 口令

```text
当我只发送「收」时，回顾本次对话，只保留对我有用的结论，去掉推导过程和客套话，按下面格式输出，并整体放进一个代码块：
【收获】标题（不超过20字）
结论：一句话
要点：
- （3–5 条，每条不超过40字）
待办：
- （没有就写「无」）
标签：#标签1 #标签2
```
